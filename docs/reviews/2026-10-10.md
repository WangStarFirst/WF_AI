# 專案 Review — 2026-10-10

## 1. 摘要

這個 repo 是個人 Toolbox,目前已有 27 個上游 skill 副本與 2 個自製 skill(`wf-project-setup`、`wf-project-review`)。最大風險是 Toolbox 還沒有任何可安裝的形式:新專案沒有辦法取得 `wf-project-setup`,而它正是 Setup 流程的起點。其次是根目錄缺 `README.md` 與 `LICENSE`,以及一份過時的更新說明。時效性資料不足(所有提交都在同一天)。

## 2. 專案與目標

**Review 的理解**:Toolbox 是使用者個人常用 skill 與自製 plugin 的來源 repo(Single Source of Truth)。`wf-project-setup` 與 `wf-project-review` 在 Target project 中執行。不記錄第三方 plugin 清單(訪談 Q1 決定)。

**落差**:目標只在 `GLOSSARY.md:3` 的一句話,以及使用者的需求描述中。根目錄沒有 `README.md`,因此「未見於面向使用者的文件」。

## 6. 建議

### 刪改

1. **補根目錄 `README.md` 與 `LICENSE`**(優先級:高)
   理由:目標與使用方式目前只存在於對話與詞彙表;自製內容沒有授權聲明。`README.md` 寫目的、結構、安裝與使用;`LICENSE` 建議 MIT(與上游一致)。涉及檔案:新增 `README.md`、`LICENSE`。
2. **修正 `.claude/skills/README.md` 的更新說明**(優先級:中)
   理由:`:6` 已與現況矛盾,且 Setup 會附加重複的 SHA 記錄。更新上游副本改為在本 repo 執行 `/wf-project-setup`。涉及檔案:`.claude/skills/README.md`。
3. **`GLOSSARY.md` 術語對齊**(優先級:中)
   理由:避免詞彙表與 skill 名稱各說各話。採用 `wf-project-setup`、`wf-project-review` 為術語,移除別名,新增 **Upstream**(指 mattpocock/skills)。涉及檔案:`GLOSSARY.md`。

### Agent 架構

4. **保留 27 個上游副本,並由 Setup 管理**(優先級:中)
   理由:保留供本 repo 使用;改由 Setup 更新,避免手動複製造成版本漂移。自製與上游的邊界在 plugin 化後自然分開。涉及目錄:`.claude/skills/`。

### 未來發展

5. **把 Toolbox 做成可安裝的 plugin**(優先級:高)
   理由:沒有它,新專案無法取得 `wf-project-setup`,Toolbox 的核心用途不成立。新增 `.claude-plugin/plugin.json` 與 `marketplace.json`,只含 `wf-*` skill;上游 skill 不放進 plugin。涉及檔案:新增 `.claude-plugin/`。
6. **為 `install-upstream.sh` 加 smoke 測試**(已決定不做)
   使用者在訪談中決定不做;列於此供日後參考。目前腳本只靠人工驗證過。

資料不足:文件時效性,待專案有更長的提交歷史後再評估。
