# LICENSE 選項(給 wf-project-setup 呈現用)

呈現給使用者時,每個選項都要附「說明」與「適用場景」。預設為 MIT。

| 選項 | `gh api /licenses/<key>` 的 key | 說明 | 適用場景 |
| --- | --- | --- | --- |
| **MIT**(預設) | `mit` | 非常寬鬆。任何人可自由使用、修改、商用、再散布,只需保留版權與授權聲明。 | 個人專案、工具、範例、想讓更多人採用且不介意被閉源使用時。 |
| **Apache-2.0** | `apache-2.0` | 寬鬆,同 MIT,另外明確授予專利權並有專利訴訟終止條款;修改處需標示。 | 可能涉及專利、企業或團隊使用、希望對貢獻者與使用者都有專利保護時。 |
| **GPL-3.0** | `gpl-3.0` | Copyleft。散布修改版或衍生作品時,必須以同樣的 GPL 釋出原始碼。 | 希望改進成果必須回饋社群、不願被閉源產品包走時。 |
| **不加** | — | 不附授權。法律上預設保留所有權利,他人無權使用、修改或散布。 | 純私人、不打算分享的專案;公開 repo 不建議。 |
